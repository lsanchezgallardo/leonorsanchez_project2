# Project Overview

La Vida es un Carnaval by Celia Cruz is a song that brings unity to all even when facing life struggles. It's about how life should be celebrated, even when it gets difficult. Not letting the struggles take your joy and hope away. The song shines a light on celebration, unity, hope, encouragement, and shared struggles. It's a song that motivates you to keep moving forward with hope, when you feel like everything is against you in the moment. It conveys community because it brings people together and motivates hope, especially for people who are sharing similar struggles.    

Project 2 will be a reflection of 'La Vida Es Un Carnaval', displaying the lyrics I selected to describe the feeling of community.

# Technical Overview

### Structure

Project 2 will be a step-by-step webpage built with HTML and CSS. Users interact with the webpage by clicking on the final word of each lyric line, creating a guided experience through smooth transitions. 

Including:

- index.html
- style.css

### Design

Interaction Design with motion and transitions:

- Final word of each lyric line is a clickable element creating guidance and revealing the next lyric line. 
- CSS used for visual design, transitions, and typography. 
- Visual effects on lyric words to guide the user's attention. 
- Images not permitted, typography is approached as imagery in this concept. 

### Layout and Styling

- Layout built through CSS
- Visual hierarchy displayed through presentation (colors, spacing, typography, effects)
- Interactive elements styled to guide users to the next lyric line. 

### Limitations

- No images or graphics.

Note - Only use typography. Visuals created through CSS, using text only. HTML used for typing text.
